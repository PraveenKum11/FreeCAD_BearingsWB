# Bearings Workbench for FreeCAD: Plan

Scope, decisions and roadmap. Update it whenever a decision changes.

## 1. Decisions

A workbench for parametric bearings, in the spirit of
[FastenersWB](https://github.com/shaise/FreeCAD_FastenersWB): pick a series and a size, or
click a hole or shaft edge, and get a correctly sized bearing that stays parametric.

## 2. Layout

The workbench owes its structure to [FastenersWB](https://github.com/shaise/FreeCAD_FastenersWB).

```
BRutils.py              paths, icon helper
BearingData.py          series registry, CSV loading, designations, search, auto-match
BearingGeometry.py      computed internals and Part shapes (no documents, no GUI)
BearingBase.py          the bearing FeaturePython object and view provider
BRselection.py          edge helpers: global coordinates, shaft vs hole
BearingsCmd.py          insert commands, toolbar drop-downs per family
PrintableBearing*.py    3D-printable bearing (PartDesign) and its task panel
BearingSearchGui.py     Find bearing
BearingBOM*.py          bill of materials (headless logic + panel)
BRData/*.csv            dimension tables
Icons/, images/         generated by tools/make_icons.py, tools/render_images.py
tests/                  headless unittest suite; tests/gui/ GUI smoke test
docs/                   GitHub wiki source, published by .github/workflows/wiki.yml
tools/dev/              git-ignored: SKF cross-check scripts and their data
```

Only `InitGui`, `BearingsCmd` and the `*Gui` modules import `FreeCADGui`, so everything else
runs headless.

## 3. Families

`BearingData.SERIES` maps a series to its table, default size and family;
`BearingGeometry.build` dispatches on the family.

| Family | Series | Table | Notes |
|---|---|---|---|
| Deep groove | 60, 62, 63, 68, 69, MR, R | `iso15_*.csv`, `mr.csv`, `inch_r.csv` | Closures Open/Z/ZZ/RS/2RS, flanged F/MF/FR |
| Angular contact | 72, 73 | from 62 / 63 | 40° (suffix B), unequal shoulders, open only |
| Self-aligning | 12, 13, 22, 23 | from 62 / 63, `iso15_22/23.csv` | Two ball rows, spherical outer raceway |
| Cylindrical | NU2, NU3, NU22, NU23 | from 62 / 63 / 22 / 23 | `Variant` NU / NJ |
| Tapered | 302, 303, 320 | `tapered.csv` | Cone, cup and rollers share one apex |
| Needle | HK, NK | `needle.csv` | No inner ring, needles run on the shaft |
| Thrust | 511, AXK | `thrust_511.csv`, `axk.csv` | AXK `Variant` adds two AS washers |
| Linear | LM | `linear_lm.csv` | LM / LUU, flanged LMF (round) / LMK (square) |

Derived series (`BearingData.DERIVED`) reuse another table where ISO 15 shares the boundary
dimensions, leaving out the smallest sizes those types aren't made in.

## 4. Data

- CSV columns: `Designation,d,D,B,r` plus `B_shielded` (wider closed miniatures) and
  `D1,C1` (flange). Families with more dimensions have their own columns (tapered T/B/C,
  LM grooves and flanges). `#` lines are comments.
- Sources: ISO 15 / 104 / 355 boundary tables, ABMA inch sizes, public maker tables
  (Samick for LM, PTI and BKZ for tapered cone and cup widths), common miniature listings.
- Every table is cross-checked against SKF's public product tables with the git-ignored
  `tools/dev/verify_skf.py`; only the comparison is kept, nothing fetched is stored:
  - all ISO series, 511, 72/73, 12/13/22/23, NU, tapered (d, D, T), needle and AXK match;
  - R: all closed widths match; open R6 differs by rounding (7/32"); open R8 / R10 keep the
    standard 1/4" / 9/32" where SKF lists its own wider designs;
  - corner radii taken from SKF where it gives standard ISO 582 values (688/689, 6804,
    MR52, MR62, MR106, MR126); 6816, 6817, 6915 keep the ISO values;
  - MR62 and MR115 share d × D with ISO 692 / 685: two naming families, both kept;
  - not sold by SKF (unverified): 636–639, 691, 6919, 6920, MR117, MR137, HK0708 and the
    smallest R sizes.
- Approximate: miniature shielded widths and flange dimensions (vendor-dependent).

## 5. Computed internals

Deep groove (`wall = (D − d)/2`): pitch `dm = (d + D)/2`; ball = largest standard ball
≤ `min(0.6·wall, 0.7·B)`; count = `max(5, round(0.6·π·dm/Dw))`, capped so balls don't
touch; groove radii 0.515 / 0.525·Dw; shoulders at `dm/2 ∓ 0.3·Dw`. Against SKF's shoulder
and recess diameters this is within a few percent of the section height (608: ≈ 0.2 mm).

Rings are revolved 2D profiles with the raceways in them, so only cages, flange holes and
retainer slots need booleans. Cages are modelled for ball bearings only; for roller and
needle bearings Detailed equals Standard.

## 6. The bearing object

`Part::FeaturePython`, proxy `BearingBase.BearingObject`. Properties: `Series`,
`Designation` (`Auto` matches the attached edge), `Closure`, `Flanged`, `FlangeShape`,
`Variant`, `DetailLevel` (Envelope / Standard / Detailed), `MatchTo` (Shaft = bore,
Housing = OD), `BaseObject`, `Invert`, `Offset`, plus read-only info (full designation,
sizes, ball size and count). Properties that don't apply to a family are hidden.

- Frame: axis +Z, the bearing occupies z ∈ [−B, 0]. Attached, z = 0 is on the clicked
  edge's face and the bearing goes into the material: into a hole, onto a shaft. A
  flanged bearing in a hole rests its flange on the face.
- Labels follow the designation until the user renames the object; repeats get a counter
  (`608`, `608_001`, …), never FreeCAD's `609`.
- Old documents get new properties when opened.

## 7. Tools

- **Toolbars**: "Bearings" has one drop-down per family; "Bearing tools" has Find bearing,
  3D-printable bearing and Bearing BOM. All panels are task panels.
- **Printable bearing**: the author's DeepGrooveBallBearing macro, ported with its
  PartDesign construction (Races / Cage / Balls bodies driven by a `BearingParameters`
  datum). Modes: create races, groove a selected body, replace a standard bearing. Live
  preview, catalog sizes, ball presets, and a status line instead of automatic resizing.
  The macro is kept in step with it, minus the workbench-only parts.
- **Find bearing**: name (prefixes, flange and closure codes, SKF names), ID, OD, height,
  ± tolerance.
- **Bearing BOM**: counts bearings (App::Link copies included), printable bearings, and
  the balls and washers to buy; CSV export.

## 8. Testing and tooling

- `freecadcmd tests/run_tests.py`: unittest. Every row × closure × flange × variant ×
  detail level (Detailed on a sample), checking validity, size, bore clearance, part count
  and overlaps; plus object, label, persistence, search, BOM and printable-bearing tests
  (preview vs. build). `BEARINGS_TESTS=<module>` runs one module.
- `tests/gui/run_gui.sh tests/gui/gui_smoke.py <log>`: drives the panels in a real FreeCAD
  and exits by itself; message boxes are stubbed so nothing waits for a click.
- `ruff format . && ruff check .` (settings in `pyproject.toml`).
- Don't name scripts `inspect.py`: it shadows the stdlib and freecadcmd prints nothing.

## 10. Risks and open questions

- Toponaming: `BaseObject` stores an edge name, which can change when the base changes.
- Performance: keep Standard as the default, cache shapes, never fuse balls.
- Static type checking: FreeCAD modules have no type information; choose between
  `freecad-stubs` and checking only the pure modules. Ruff covers the basics.
- Repo and Addon Manager name ("Bearings").
- Confirm miniature flanges and the SKF-unlisted rows against a miniature vendor sheet.
- Candidate tables: 160xx, 622xx / 623xx, 617/x and 618/1.5–2.5 ultra-miniatures.
