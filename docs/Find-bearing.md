# Find bearing

**Bearing tools → Find bearing** searches every table by any combination of:

- **Name**, or the start of one: `608`, `62` (all 62xx), `F688-2RS`, `MF105ZZ`, `FR188ZZ`,
  `6204-2RS1`, SKF-style `618/8`, `7204 BEP`, `NU2205 ECP`, `NJ204`, `30204 J2/Q`,
  `HK 0810`, `LMK8UU`, or a size such as `8x22` / `8x22x7`.
- **Inner diameter**, **outer diameter** and **height**, with a ± tolerance. The height
  also matches the shielded width of miniature bearings.

![Find bearing listing every bearing with a 22 mm outside diameter](images/find-bearing.png)

Flange and closure codes in the name (`F`, `MF`, `FR`, `LMF`, `LMK`, `ZZ`, `2RS`) are used
when inserting.

- **Insert bearing** adds the selected size (attached to the edges you selected before
  opening the panel, if any). Double-clicking a row does the same.
- **Printable…** opens the [[Printable bearings|3D-printable bearing]] panel with that
  size (ball bearings only).
